# Archive: MIP plans and reports from Strata-xeno

Frozen copies of the 130 MIP, IGC, Qwenputer and sandbox documents written while the work lived in
[Strata-xeno](https://github.com/xenodeve/Strata-xeno), taken from branch `xeno/general-style-dev` at `20036291` on 2026-11-08,
paths kept (`plans/`, `reports/`, `superpowers/plans/`, `QWENPUTER_FORMAT.md`).

- **They are the record, not the current state.** The current state of every mechanism and result is the [catalog](../INDEX.md);
  where a document and the catalog differ, the catalog holds (results withdrawn later are marked there).
- **Their links and `file:line` references point into Strata-xeno,** and a bare `#N` means Strata-xeno #N (map: mip-research #22).
- New plans go in [`docs/plans/`](../plans/), not here.
